# TMI Generator

SillyTavern 확장. 캐릭터 답장을 받을 때마다 재미있는 TMI(Too Much Information)를 자동 생성해서 접이식 박스로 보여줍니다. 마음에 든 TMI는 📌 로 고정해 작가노트처럼 매 요청에 함께 실어보낼 수 있습니다.

## 기능

### 생성
- 답장마다 자동 생성 (끄고 수동 버튼으로 전환 가능)
- **Main API** 또는 별도 **Connection Profile**로 생성 — 프리셋/인스트럭트 설정과 무관하게 독립 호출
- 캐릭터 정보, 페르소나, 활성화된 로어북을 컨텍스트에 포함
- TMI 개수(1~10) · 길이(짧게/중간/길게) · 출력 언어(한국어/English) · 최대 토큰 · 참고할 최근 메시지 수 설정
- **중복 회피** — 최근 TMI, 핀된 항목, 방금 재생성으로 지운 항목을 "이미 나왔음" 목록으로 함께 전달해 반복을 줄임

### 프리셋
- 기본 제공 14종(세계관, 캐릭터 감정, 감각 디테일, BGM, 소품 도감, 뉴스, 위키, SNS 타임라인, NPC 뒷담화, What-if, 다음 씬 떡밥, 전투 분석, 타로 등) — 확장 업데이트 시 자동으로 늘어남
- 프롬프트를 직접 고쳐서 "내 프리셋"으로 저장 가능 (기본 제공 프리셋은 보존됨)
- CSS도 프리셋으로 저장/전환 가능

### 핀 → 프롬프트 주입
- TMI 항목을 📌 로 고정하면 `setExtensionPrompt`를 통해 작가노트와 같은 방식으로 매 요청에 주입됨
- 주입 위치(채팅 내 @Depth / 메인 프롬프트 앞·뒤), Role, 로어북 스캔 여부, 래퍼 템플릿을 직접 지정
- 확장 메뉴(🪄) → **TMI 관리** 패널에서 핀 목록 확인, 문장만 따로 편집(원문 보존), 실제 주입 텍스트 미리보기, 예상 토큰 수 확인, 해당 메시지로 이동

### 데이터
- TMI는 `message.extra`에 저장되어 채팅 파일을 따라갑니다 (내보내기·브랜치해도 유지) — 메시지 삭제/스와이프와 자연스럽게 연동
- 구버전(1.0.x)에 저장돼 있던 TMI는 채팅을 열 때 자동으로 이전됩니다

## 사용법
1. `SillyTavern/public/scripts/extensions/third-party/`에 이 저장소를 클론
2. SillyTavern 재시작 후 확장 목록에서 **TMI Generator** 활성화
3. 확장 설정에서 API 소스·프리셋·언어 등을 원하는 대로 조정
4. 답장 아래 뜨는 TMI 박스에서 항목에 마우스를 올리면 나오는 📌 로 고정
